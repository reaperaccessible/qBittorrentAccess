Overview

qBittorrentAccess lets you download torrent files and magnet links on your own with your screen reader (NVDA, JAWS, Narrator), using the keyboard only. It is qBittorrent, a well-known free program, fast and ad-free, with every screen reviewed for screen readers:

  • every list, button, option and menu has a clear name;
  • every window says what it is for and which keys to use when it opens;
  • shortcuts take you straight to each part of the program;
  • values are spelled out (sizes, speeds, durations), never abbreviated;
  • the value you read stays on your braille display.

At any time, Ctrl+Shift+H shows the list of all shortcuts, F1 opens this manual and Ctrl+F1 the changelog.

BitTorrent in a nutshell: a torrent file (or a magnet link) does not contain the film or the music, only the description of the files. qBittorrentAccess downloads these files piece by piece from other people who have them, and at the same time uploads the pieces it already has. When the download is complete, the torrent keeps being shared ("seeding") until you stop or remove it.

Installation and first start

The installer offers four choices: a desktop icon, not checked, and the following three, checked by default:

  • .torrent files: they open in qBittorrentAccess when you press Enter on them in File Explorer;
  • Magnet links: a magnet link activated in your web browser opens in qBittorrentAccess;
  • Allow qBittorrentAccess through the Windows firewall: recommended, so that other users can connect to you and your downloads go faster. Without it, Windows shows a security window on the first start.

On the first start, if qBittorrent is already installed on the computer, qBittorrentAccess takes a copy of its torrents and settings. Your qBittorrent is left unchanged. The log (Ctrl+8) shows it with a line starting with "Torrents and settings imported from qBittorrent".

The program follows the Windows language. To change it: Ctrl+Comma, Behavior page, Language list, then restart qBittorrentAccess.

The main window

The main window has tabs and, in the transfers tab, several areas. F6 moves to the next area, Shift+F6 to the previous one:

  1. the torrent list, the heart of the program;
  2. the properties of the selected torrent (general, trackers, peers, HTTP sources, content, speed);
  3. the filters: by status, category, tag and tracker;
  4. the filter field, to find a torrent by its name (Ctrl+F goes there directly).

The shortcuts Ctrl+1 to Ctrl+8 take you straight where you want to go, from anywhere:

  • Ctrl+1: all torrents;
  • Ctrl+2: downloading torrents;
  • Ctrl+3: completed torrents;
  • Ctrl+4: seeding torrents;
  • Ctrl+5: torrents with errors;
  • Ctrl+6: search;
  • Ctrl+7: RSS feeds;
  • Ctrl+8: execution log.

When you reach the list, the screen reader says the view and the number of torrents, for example "Torrents, Downloading (3)", then the selected torrent. If you are already there, the shortcut simply repeats the announcement.

The menu bar (Alt) holds the File, Edit, View, Tools and Help menus. In menus, Right Arrow opens a submenu and Left Arrow closes it; the screen reader tells you which items have a submenu.

Adding a download

From a torrent file

Ctrl+O opens the file selection box: choose one or more .torrent files. If the association was checked during installation, you can also just press Enter on a .torrent file in File Explorer.

From a magnet link or an address

Ctrl+Shift+O opens the Add torrent links window. First copy the link in your browser, then:

  • if the clipboard already holds links, they are taken automatically and the focus is on the Links list, which you can browse with the arrows;
  • otherwise, paste with Ctrl+V: the number of pasted links is announced. You can put one link per line.

Confirm with the Download button. A magnet link activated in the browser also opens directly in qBittorrentAccess if the association was checked during installation.

The add window

Before the download starts, a window lets you set:

  • the save folder (Ctrl+B in this field opens the folder selection box);
  • the category, tags and other torrent options;
  • the torrent information (size, free disk space, date…): a list to browse with the arrows;
  • the content: the list of files, to download only the ones you want.

For a magnet link, the information and the file list arrive after a few seconds; "Metadata received" is announced at that moment. Enter on the OK button starts the download.

Reading the torrent list

The list shows one torrent per row, with several columns: name, size, progress, status, seeds, peers, download speed, upload speed, time left, ratio, and more.

  • Up Arrow and Down Arrow move from one torrent to another;
  • Right Arrow and Left Arrow read the next or previous column of the torrent, for example "Progress 45.3%" or "ETA 12 minutes";
  • once on a column, Up Arrow and Down Arrow stay in it: you read the progress of each torrent, one after the other, without the names being repeated;
  • Home goes back to the Name column, End goes to the last column;
  • Ctrl+Home and Ctrl+End go to the first and last torrent.

At the ends of the list, the screen reader says "First" or "Last" before the value.

Braille: the value of the column you read stays on your braille display. To refresh it (a progress that moves on, for example), simply press Left Arrow then Right Arrow.

Managing torrents

In the torrent list, on the selected torrent:

  • Space starts or stops the torrent; "Started" or "Stopped" is announced;
  • Enter does the double-click action: by default, start or stop a downloading torrent, and open the folder of a completed torrent (can be changed in the Options, Behavior page);
  • Ctrl+Enter opens the folder where the torrent is saved;
  • Ctrl+Shift+C copies the magnet link of the torrent, to share it;
  • F2 renames the torrent;
  • Ctrl+M forces the start (ignoring the queue);
  • Ctrl+R forces a recheck of the files already downloaded.

Anywhere in the window:

  • Ctrl+S starts and Ctrl+P stops the selected torrents;
  • Ctrl+Shift+P pauses the whole session, Ctrl+Shift+S resumes it;
  • Ctrl+Plus and Ctrl+Minus on the numeric keypad move the torrent up or down the queue; with Shift added, it goes to the very top or bottom. Use the numeric keypad: on the main row, the plus sign already needs the Shift key.

Removing a torrent

Del removes the torrent from the list and keeps the downloaded files; Shift+Del also offers to delete the files. A confirmation opens with the focus on Cancel, for safety: Tab leads to the Also remove the content files check box, then to the Remove button. Escape cancels.

The context menu

The Applications key (or Shift+F10) opens the menu of the selected torrent: start, stop, remove, set location, rename, edit trackers, category, tags, download in sequential order, torrent options, copy, export .torrent, and more. Some items are check boxes, announced checked, not checked or partially checked (when several selected torrents do not all have the same setting); Enter toggles them.

Several torrents at once

Shift+Down Arrow extends the selection, Ctrl+A selects everything. Commands then apply to all selected torrents, except Enter and F2, which only act on a single torrent.

Torrent properties

The properties describe the selected torrent. Each tab has its shortcut, usable from the list:

  • Ctrl+Shift+1 General: a list of all the information (time active, downloaded, uploaded, speed, ratio, folder, date added, hash…), one per line, to read with the arrows. Ctrl+C copies the value of the line;
  • Ctrl+Shift+2 Trackers: the servers that put participants in touch, and their status;
  • Ctrl+Shift+3 Peers: the connected people, with their address, their program and their speeds;
  • Ctrl+Shift+4 HTTP Sources: the web sources of the torrent, if any;
  • Ctrl+Shift+5 Content: the files and folders of the torrent. You can change the priority of a file or choose not to download it, from the context menu;
  • Ctrl+Shift+6 Speed: the speed history.

The Trackers, Peers and Content lists are read exactly like the torrent list: each row is first read in full; Right Arrow and Left Arrow read one column at a time, and Up and Down then stay in that column; Home and End go to the first and last column; Ctrl+Home and Ctrl+End go to the first and last row. In Content and Trackers, which are trees, Plus opens a folder and Minus closes it. The HTTP Sources list is read row by row. Shift+F6 (or Ctrl+1) takes you back to the torrent list.

Status, statistics and log

  • Ctrl+Shift+G says the overall status without leaving where you are: total download and upload speeds, connection status, number of DHT nodes;
  • Ctrl+I opens the Statistics: all-time download and upload, global ratio, connected peers, and more, in a list to read with the arrows. Escape closes it;
  • Ctrl+8 opens the Execution Log: the messages of the program (start, errors, completed torrents…).

When a download completes, a Windows notification appears. If notifications are turned off and the qBittorrentAccess window is active, the screen reader announces the completed download.

Searching for torrents

Ctrl+6 opens the Search tab, with the focus in the search field. Search works through plugins, small programs that each query one site. Everything is ready right after installation: nothing else to install.

  • qBittorrentAccess comes with about fifteen public plugins, checked before release, installed on the first start: films, TV shows, free software, Japanese animation, and general sites;
  • the Search plugins... button opens the list of plugins: you can disable or uninstall some (an uninstalled plugin does not come back), check for their updates, or add others with Install a new one;
  • plugins are programs written in the Python language; qBittorrentAccess contains its own copy of Python to run them.

A site can close or change overnight: if a plugin no longer gives results, the site is usually the cause, not qBittorrentAccess.

Type your keywords and press Enter. The results are read exactly like the torrent list: Up Arrow and Down Arrow browse the list, each result being read in full (name, size, seeders, engine…); Right Arrow and Left Arrow read one column at a time, and Up and Down then stay in that column, to compare for example the size or the number of seeders of each result; Home and End go to the Name column and the last column; Ctrl+Home and Ctrl+End go to the first and last result. The value you read stays on the braille display. Enter downloads the result. The context menu also offers Open download window to choose the folder and the files. Filters (minimum and maximum seeds, size) let you refine the results.

RSS feeds

An RSS feed is a list of new items published by a site (for example the new episodes of a show). Ctrl+7 opens the RSS tab, with the focus on the feed list:

  • New subscription adds a feed from its address;
  • the feed list shows the number of unread articles; the article list shows the new items of the chosen feed, and the article content is shown next to it;
  • the RSS Downloader... creates rules that automatically download new items whose title contains certain words.

Creating a torrent

Ctrl+N opens the Torrent Creator: choose the file or folder to share, add tracker addresses if you have some, then create the .torrent file. You can start sharing it right away.

Options

Ctrl+Comma opens the options. The Pages list shows the sections: Behavior, Downloads, Connection, Speed, BitTorrent, Search, RSS, WebUI and Advanced. Choose a page with the arrows, then Tab goes through its settings. Every setting has a name, and the settings of a group are announced with the name of the group. The OK, Cancel and Apply buttons are at the bottom of the window.

Useful settings:

  • Downloads, Default Save Path: the folder where your downloads go;
  • Speed: limit the download and upload speed, so as not to saturate your connection;
  • Behavior: the language, starting with Windows, the icon in the notification area, the Enter (double-click) action in the list;
  • BitTorrent: the seeding limits (stop a torrent after a given ratio or time).

In the Tools menu, On Downloads Done lets you exit the program, put the computer to sleep or shut it down when everything is downloaded.

Where are my files?

  • Downloaded files go to your Downloads folder by default; the add window lets you choose another one for each torrent. Ctrl+Enter on a torrent opens its folder.
  • Your settings and your list of torrents are in your Windows profile (qBittorrentAccess folders in AppData).
  • Uninstalling qBittorrentAccess deletes neither your downloads nor your settings: if you install it again, you get everything back.

All keyboard shortcuts

This list is also in the program: Ctrl+Shift+H.

Going somewhere

  • Ctrl+1 to Ctrl+5: torrent list, all, downloading, completed, seeding, errors
  • Ctrl+6: search
  • Ctrl+7: RSS
  • Ctrl+8: execution log
  • Ctrl+Shift+1 to Ctrl+Shift+6: properties, General, Trackers, Peers, HTTP Sources, Content, Speed
  • F6, Shift+F6: next, previous area
  • Ctrl+F: filter torrents by name

In the torrent list

  • Left Arrow, Right Arrow: read one column; Up and Down then stay in it
  • Home, End: Name column, last column
  • Ctrl+Home, Ctrl+End: first torrent, last torrent
  • Space: start or stop the torrent
  • Enter: double-click action
  • Ctrl+Enter: open destination folder
  • Ctrl+Shift+C: copy magnet link
  • F2: rename
  • Ctrl+M: force start
  • Ctrl+R: force recheck
  • Del: remove torrent; Shift+Del: remove torrent and its files
  • Applications: context menu

In the search results, trackers, peers and content

  • Left Arrow, Right Arrow, Home, End, Ctrl+Home, Ctrl+End: as in the torrent list
  • Plus, Minus: open, close a folder, in the content and the trackers
  • Enter: download the result, in the search results

General commands

  • Ctrl+O: open torrent file
  • Ctrl+Shift+O: add torrent link, magnet
  • Ctrl+N: create new torrent
  • Ctrl+S, Ctrl+P: start, stop the selected torrents
  • Ctrl+Shift+S, Ctrl+Shift+P: resume, pause the session
  • Ctrl+Plus, Ctrl+Minus (numeric keypad): move up, down in the queue
  • Ctrl+Shift+Plus, Ctrl+Shift+Minus (numeric keypad): top, bottom of the queue
  • Ctrl+Shift+G: global status, speeds, connection, DHT
  • Ctrl+I: statistics

Updates and help

Updates of qBittorrentAccess are offered by the ReaperAccessible Installer Manager. You can also download the latest installer, always at the same address:
https://github.com/reaperaccessible/qBittorrentAccess/releases/latest/download/qBittorrentAccessInstaller.exe

The Help menu holds this manual (F1), the changelog (Ctrl+F1), the list of shortcuts (Ctrl+Shift+H) and the About window.

To report a problem: https://github.com/reaperaccessible/qBittorrentAccess/issues, or through the reaperaccessible.fr website. Please do not report qBittorrentAccess problems to the qBittorrent project.
